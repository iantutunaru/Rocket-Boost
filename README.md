# Rocket Boost

Rocket Boost began as a tutorial-based Unity project developed while following the **Complete C# Unity 3D Game Development in Unity 6** course.

## Project Status

The traditional format of directly following the tutorial has been shifted in favor of re-creating new material independently and reinforcing existing Unity/C# knowledge through a separate practice project.

Further experimentation, re-implementation, and knowledge training are now focused on the **Forge** project:

[Forge](https://github.com/iantutunaru/Forge)

## Purpose

This repository remains as a record of the original learning path.
